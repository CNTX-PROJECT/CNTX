# CNTX Public-Core release policy

This directory contains documentation-only policy sources for the prospective
CNTX Public Core release lifecycle. It supplies no release record, active
release version, tag, GitHub Release, manifest, package, archive, publication,
distribution, support service, certification, or deployment.

## Lifecycle and authority

The policies below are **Proposed** under
[REMEDIATE-002 issue #86](https://github.com/CNTX-PROJECT/CNTX/issues/86) and
attributable EIGENAAR / Final Authority creation comment `5226346595`.
Repository presence, validation, a Draft pull request, or transparent
non-independent ARCHITECT review does not accept or activate them.

Acceptance of an exact policy candidate, if separately authorized and
integrated, would accept only the documented decision basis. It would not
approve a release or authorize a tag, GitHub Release, package, publication,
support claim, correction, withdrawal, distribution, or deployment. Every
consequential phase requires separate attributable authority.

## Current position

CNTX remains unreleased and pre-alpha. `CNTX Public Core Release` is only a
Proposed logical identity. `0.1.0-prealpha.1` and
`v0.1.0-prealpha.1` are prospective decision inputs only. No active Release
Version or tag exists, and no GitHub Release has been created.

These documents make no supported-version, compatibility, security, privacy,
legal, compliance, production-readiness, fitness, warranty, certification, or
absence claim. Final release authority remains exclusively with a later
separate attributable EIGENAAR / Final Authority decision.

# CNTX Public-Core release policy

This directory contains documentation-only policy, decision, and Accepted
execution sources for the prospective CNTX Public Core release lifecycle. It
supplies no package, custom archive, manifest, support service, certification,
implementation, or deployment.

## Lifecycle and authority

The policies below are **Accepted** under
[REMEDIATE-002 issue #86](https://github.com/CNTX-PROJECT/CNTX/issues/86) and
attributable EIGENAAR / Final Authority creation comment `5226346595` and
exact-head acceptance comment `5226499010`.
Accepted status and governed integration establish only the documented
decision basis and do not activate a release.

Acceptance and integration of the exact policy candidate accept only the
documented decision basis. They do not
approve a release or authorize a tag, GitHub Release, package, publication,
support claim, correction, withdrawal, distribution, or deployment. Every
consequential phase requires separate attributable authority.

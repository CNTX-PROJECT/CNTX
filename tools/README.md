# CNTX tools

This directory contains the bounded public implementation material used to
exercise specific Accepted CNTX contracts. It is a technical path, not a
product download page.

## Current public slice

- [Minimal Validation and Integrity Slice](minimal-validation-integrity-slice/README.md)
  — the governed and integrated minimal local slice for the Accepted Tool and
  Implementation contracts in ARCH-037.
- [Cross-record integrity practice](minimal-validation-integrity-slice/practice/cross-record-integrity/README.md)
  — four bounded practice scenarios with thirteen separate rule outcomes.

`Accepted schemas and cases → minimal local tool → individual results → evidence and human review remain separate`

The slice was installed and executed only inside separately authorized,
isolated temporary environments. The environments and installed dependencies
were removed afterward. The historical schema cases matched their fixed
expected results (`203/38/165`), and the practice outcomes remain separate;
neither observation is an aggregate conformance result.

## Boundary

Repository presence does not install the tool, keep its dependencies present,
create network-isolation proof, establish support, certify CNTX, approve a
release, prove deployment fitness, or grant final-human authority. The slice is
minimal and bounded; it is not a complete adversarial or production test suite.

# Security Policy

## Supported versions

CNTX is pre-alpha and has no supported release line yet. Security fixes, if accepted, are evaluated against the current `main` branch. No compatibility or response-time commitment is implied.

## Reporting a vulnerability

Do **not** report security vulnerabilities in public GitHub issues. Public issues are not a security-reporting channel.

Use GitHub private vulnerability reporting for this repository when it is available in the repository settings. Its availability depends on those settings. If it is not available, use an available private maintainer or repository contact mechanism rather than publishing the details publicly.

Do not include secrets, credentials, private context, personal data, production configurations, or exploitable details in public reports, issues, pull requests, commits, or comments.

## Responsible disclosure

A useful private report includes a concise description, affected revision or path, reproduction steps or proof of concept, impact, likely attack prerequisites, and any suggested mitigation. Please allow maintainers time to assess and coordinate a response before public disclosure. Do not exploit vulnerabilities beyond what is necessary to demonstrate the issue.
